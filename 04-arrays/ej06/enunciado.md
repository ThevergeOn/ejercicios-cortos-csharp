# Ejercicio 6

Partiendo de un array de números enteros, crea un nuevo array con los mismos elementos; cada elemento del nuevo array será la suma del mismo elemento más el elemento anterior más el elemento siguiente del array del que partimos. Los elementos anterior al primer elemento y siguiente al último serán cero. Por ejemplo: Array de entrada = [3, 7, 5, 9]. Array de salida = [10, 15, 21, 14].

## Soluciones

Cada persona tiene su carpeta dentro de [`soluciones/`](soluciones/). La carpeta [`referencia`](soluciones/referencia/Program.cs) tiene una solución posible, no la única.
