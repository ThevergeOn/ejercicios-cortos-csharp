# Ejercicio 20

Crea un método que convierte una tabla dentada en una matriz añadiendo cero en las posiciones que no existen. Array de entrada = [[1, 2, 3], [11, 12], NULL, [41, 42, 43, 44, 45], [51], [61, 62]].

```text
Matriz de salida:
[ 1,  2,  3,  0,  0]
[11, 12,  0,  0,  0]
[ 0,  0,  0,  0,  0]
[41, 42, 43, 44, 45]
[51,  0,  0,  0,  0]
[61, 62,  0,  0,  0]
```

## Soluciones

Cada persona tiene su carpeta dentro de [`soluciones/`](soluciones/). La carpeta [`referencia`](soluciones/referencia/Program.cs) tiene una solución posible, no la única.
