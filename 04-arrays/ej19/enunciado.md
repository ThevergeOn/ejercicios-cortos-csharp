# Ejercicio 19

Crea un método que, dada una matriz, añade una fila y una columna con la suma de los elementos de cada fila y columna.

```text
Matriz de entrada  Matriz de salida
[1, 2, 3]          [ 1,  2,  3,  6]
[4, 5, 6]          [ 4,  5,  6, 15]
[7, 8, 9]          [ 7,  8,  9, 24]
                   [12, 15, 18, 45]
```

## Soluciones

Cada persona tiene su carpeta dentro de [`soluciones/`](soluciones/). La carpeta [`referencia`](soluciones/referencia/Program.cs) tiene una solución posible, no la única.
