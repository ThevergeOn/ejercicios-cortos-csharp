# Ejercicio 22

Crea un método que traspone una tabla dentada: todos los elementos que ocupan la primera posición en los distintos arrays de la tabla dentada formarán parte del primer array. Los que ocupan la segunda posición, el segundo y así sucesivamente. Array de entrada = [[1, 2, 3], [11, 12], NULL, [41, 42, 43, 44, 45], [51], [61, 62]]. Array de salida = [[1, 11, 41, 51, 61], [2, 12, 42, 62], [3, 43], [44], [45]]
