# Ejercicio 17

Crea un método que, dada una tabla dentada de entrada, invierte los valores de los arrays que la componen. Array de entrada = [[1, 2, 3], [11, 12], NULL, [41, 42, 43, 44, 45], [51], [61, 62]]. Array de salida = [[3, 2, 1], [12, 11], NULL, [45, 44, 43, 42, 41], [51], [62, 61]]

## Soluciones

Cada persona tiene su carpeta dentro de [`soluciones/`](soluciones/). La carpeta [`referencia`](soluciones/referencia/Program.cs) tiene una solución posible, no la única.
