# Ejercicio 18

Crea un método que, dada una tabla dentada de entrada, invierte los arrays que la componen. Array de entrada = [[1, 2, 3], [11, 12], NULL, [41, 42, 43, 44, 45], [51], [61, 62]]. Array de salida = [[62, 61], [51], [45, 44, 43, 42, 41], NULL, [12, 11], [3, 2, 1]]
