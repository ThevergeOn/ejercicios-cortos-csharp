# Ejercicio 11

Dado un array de entrada de números enteros positivos, calcula el número que más veces se repite. Deberás dar una pasada al array de entrada para obtener su valor máximo. Luego tienes que crear un nuevo array de 0 hasta el valor máximo donde guardarás cuántas veces se repite cada número. Por último debes recorrer el nuevo array para ver cuál es el número que más se repite. En el caso de que haya varios valores que son el máximo, darás todos esos valores. Array de entrada = [1, 3, 1, 0, 1, 5, 5, 2, 5]. El valor o valores que más se repiten: 1, 5
