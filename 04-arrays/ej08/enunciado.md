# Ejercicio 8

Crea un método que nos indique si los elementos de dos arrays de la misma longitud son parecidos. Dos números son parecidos si son el mismo número o uno es el anterior o siguiente del otro. Los dos arrays A y B son parecidos, B y C también son parecidos, pero A y C no lo son. Array A: [3, 7, 5, 9]. Array B: [4, 7, 4, 8]. Array C: [4, 8, 3, 9].
