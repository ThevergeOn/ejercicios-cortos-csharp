# Ejercicio 14

Crea un método que dados dos arrays de la misma longitud que podríamos llamar A y B, crea un tercer array en el que el primer elemento de A se repite tantas veces como indica el primer elemento de B y así con el resto de elementos. Si un elemento del array B es cero, su correspondiente elemento de A no se pone. Array A = [3, 1, 0, 5, 2]. Array B = [1, 2, 3, 0, 2]. Array salida = [3, 1, 1, 0, 0, 0, 2, 2]
