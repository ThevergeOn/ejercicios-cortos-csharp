# Ejercicio 10

Dado un array de entrada con números enteros, crea un array de salida en el que cada elemento del array de entrada se repite tantas veces como indica su número. Ejemplo: Array de entrada = [3, 1, 0, 5, 2]. Array de salida = [3, 3, 3, 1, 5, 5, 5, 5, 5, 2, 2]. Nota: fíjate que como el cero se repite "cero" veces, en realidad, se elimina.

Cada persona tiene su carpeta dentro de [`soluciones/`](soluciones/). La carpeta [`referencia`](soluciones/referencia/Program.cs) tiene una solución posible, no la única.
