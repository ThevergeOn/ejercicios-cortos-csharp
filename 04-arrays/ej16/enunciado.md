# Ejercicio 16

Crea un método que dado un array de entrada, cree un array dentado en el que cada array sea el valor que indica la misma posición del array de entrada repetido tantas veces como indique ese valor. Si un elemento es cero, su array no existe, es decir, tiene NULL. Array Entrada = [3, 1, 0, 5, 2]. Array Dentado = [[3, 3, 3], [1], NULL, [5, 5, 5, 5, 5], [2, 2]]

## Soluciones

Cada persona tiene su carpeta dentro de [`soluciones/`](soluciones/). La carpeta [`referencia`](soluciones/referencia/Program.cs) tiene una solución posible, no la única.
