# Ejercicio 13

Crea un método que dados dos arrays, que podrían tener tamaños diferentes, los mezcla en un nuevo array cogiendo uno, dos o tres elementos de cada array de manera alternativa. El que coja uno, dos o tres elementos será aleatorio. Cuando un array se acabe, se añadirán los elementos restantes del otro.

## Soluciones

Cada persona tiene su carpeta dentro de [`soluciones/`](soluciones/). La carpeta [`referencia`](soluciones/referencia/Program.cs) tiene una solución posible, no la única.
