# Ejercicio 15

Crea un método que dado un array, crea dos nuevos arrays guardando los elementos que ocupan una posición par del primer array en uno y los que ocupan una posición impar en el otro. Array Entrada = [3, 1, 0, 5, 2]. Array salida A = [3, 0, 2]. Array salida B = [1, 5]
