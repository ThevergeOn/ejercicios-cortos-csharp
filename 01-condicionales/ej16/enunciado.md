# Ejercicio 16

Dados tres lados de un triángulo: comprobar si pueden formar un triángulo. Si pueden: comprobar si es equilátero, isósceles o escaleno. Para comprobar si existe el triángulo se deben cumplir: lado1 + lado2 > lado3, lado1 + lado3 > lado2, lado2 + lado3 > lado1. Equilátero: tres lados iguales. Isósceles: dos lados iguales. Escaleno: ningún lado igual.
