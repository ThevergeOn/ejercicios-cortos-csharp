# Ejercicio 34 (zigzag)

Debes hacer que el * siga la secuencia que indican los números: primero la posición 1, luego la 2 y así.

```text
14589...
2367....
```

## Soluciones

Cada persona tiene su carpeta dentro de [`soluciones/`](soluciones/). La carpeta [`referencia`](soluciones/referencia/Program.cs) tiene una solución posible, no la única.

¿Quieres añadir la tuya? Lee [CONTRIBUTING.md](../../CONTRIBUTING.md).
